# Dashboard project guidance

Use [idea.md](idea.md) for product intent and [ALPHA_GUIDE.md](ALPHA_GUIDE.md) for the alpha build order when relevant to a task.

For PM check-ins, backlog management, milestone planning, or alpha release reviews, follow [PM_AGENT.md](PM_AGENT.md) and update [PROJECT_STATUS.md](PROJECT_STATUS.md) from evidence. Ordinary implementation tasks do not need a separate PM approval.
