# Подключение нового Windows VPS с MT5

Центральный сервер — Linux VPS `https://46.225.132.195`. На новом Windows VPS локальный веб-сервер и PostgreSQL не нужны. Работай под пользователем, который запускает MT5. Для регистрации задач открой PowerShell с правами администратора **под этой же учётной записью**.

[scripts/setup_host.ps1](../scripts/setup_host.ps1) объединяет три этапа: `Prepare` создаёт предложения для проверки, `Install` устанавливает их, `Check` проверяет результат. Действующую установку он не перезаписывает.

| Профиль | Что подключается |
|---|---|
| `Logs` | Journal, Experts, heartbeat и процессы MT5 |
| `Accounts` | Всё из Logs плюс связь с брокером, AutoTrading, позиции, сделки и PnL |
| `Full` | Всё из Accounts плюс подготовка EA-сервиса и отдельный монитор доступности центрального HTTPS-сервера с Telegram |

## 1. Зарегистрируй хост на центральном сервере

Выбери постоянный уникальный `host_id`, например `mt5-win-02`. По умолчанию используется имя Windows-компьютера в нижнем регистре. Администратор центрального VPS генерирует отдельный случайный токен минимум 32 символа и добавляет пару host_id → токен в JSON переменной `DASHBOARD_HOST_TOKENS` в `/etc/mt5-dashboard/central.env`, **сохраняя существующие пары**, затем перезапускает `mt5-dashboard`. Файл остаётся с правами `0600` и владельцем `dashboard`. См. [настройку Linux VPS](linux-vps.md). Токены разных хостов должны отличаться.

Передай токен защищённым способом. Установщик запросит его скрытым вводом и зашифрует Windows DPAPI. Пароли браузера, SSH и брокера сборщику не нужны. Не помещай токены в Git, сообщения, отчёты или аргументы задач. Порты API и PostgreSQL наружу открывать не требуется.

## 2. Подготовь проект и Python

Если проекта ещё нет:

```powershell
git clone --branch main https://github.com/mishadev-algo/dashboard.git C:\dashboard
Set-Location C:\dashboard
```

Если проект уже есть, сначала проверь локальные изменения и обнови исходники, сохранив локальные базы и настройки. Установи **64-битный Python 3.13** по [инструкции сборщика](collector.md), если его нет. Скрипт ищет стандартный пользовательский путь `Python313\python.exe`, затем `python.exe` в PATH; launcher `py` не обязателен. Для другой установки передай полный `-PythonExe`.

Открой все нужные MT5 и проверь подключение к брокерам. Подготовка сопоставляет процессы с папками данных по `origin.txt`; portable-терминалы также обнаруживаются по исполняемому файлу.

```powershell
Invoke-RestMethod https://46.225.132.195/health
.\scripts\setup_host.ps1 -Mode Prepare -Profile Full `
    -ServerUrl https://46.225.132.195 -HostId mt5-win-02 `
    -DayTimezone 'Etc/GMT-3' -InstallDependencies
```

`-InstallDependencies` устанавливает `MetaTrader5` и `tzdata` в выбранный Python. Для Logs они не требуются. Если зависимости уже есть, флаг можно убрать. `Etc/GMT-3` означает **фиксированный UTC+3**, без летнего времени; по умолчанию — UTC. История по умолчанию — 7 дней.

Для нестандартных папок добавь `-Roots` и `-Terminals`:

```powershell
.\scripts\setup_host.ps1 -Mode Prepare -Profile Accounts `
    -ServerUrl https://46.225.132.195 -HostId mt5-win-02 `
    -PythonExe 'D:\Python313\python.exe' -DayTimezone 'Etc/GMT-3' `
    -Roots @((Join-Path $env:APPDATA 'MetaQuotes\Terminal'), 'D:\MT5Data') `
    -Terminals @('D:\PortableMT5') -PlanDir host-setup-review
```

## 3. Проверь предложения

Prepare сохраняет папку `host-setup`, игнорируемую Git:

- `plan.json`: хост, URL, профиль, Python, пути, наблюдения и замечания;
- `inventory.json`: работающие терминалы в expected, подтверждённо остановленные старые папки в archived;
- `accounts.json`: login/server, часовой пояс и история, если выбран Accounts или Full.

Рабочие файлы, база и задачи на этом этапе не меняются. Скрипт не отправляет ордера, не переключает AutoTrading и не выполняет вход с брокерским паролем.

Сверь **File → Open Data Folder** в каждом MT5 с expected. Если несколько папок ссылаются на одну установку, оставь фактическую папку данных. Покрой все работающие MT5 этого пользователя. Недоступные пути процессов и несопоставленные терминалы требуют исправления.

Сверь login/server в accounts.json с MT5. Если API не прочитал счёт, предложение содержит `login: 0`, пустой server и замечание: введи проверенные значения вручную. Install отклоняет пустые значения и обнаруженное несовпадение. Недоступный брокеру счёт можно оставить под мониторингом: установка предупредит, а Check не признает его готовым до появления полного снимка. Чтобы исключить его, сначала останови терминал и скорректируй inventory/accounts.

Не переноси `collector-central.db`, `.dashboard-*.local.json` и план с другого VPS: база хранит host_id, смещения и очередь, а секреты зашифрованы для конкретного пользователя. Prepare не перезаписывает непустую папку предложений; для нового прохода укажи новый `-PlanDir`.

## 4. Установи и запусти

После проверки файлов:

```powershell
.\scripts\setup_host.ps1 -Mode Install -PlanDir host-setup
```

Профиль, Python, хост и URL берутся из плана. Скрипт повторно проверяет процессы и счета, сохраняет конфигурацию, создаёт или повторно использует collector-central.db, выполняет первую отправку с проверкой ответа API, регистрирует и запускает `MT5CollectorRemote`. Accounts/Full запускают оба worker-процесса под общим супервизором.

Full дополнительно запросит Telegram bot token и chat ID, сохранит их в отдельном `.dashboard-monitor.local.json`, зарегистрирует и запустит `MT5DashboardMonitor`. Старый `.dashboard-start.local.json` новой установке не нужен. Этот монитор проверяет доступность центрального HTTPS-сервера; терминальные и брокерские уведомления обслуживает центральная система alerts.

Для Full исходник `DashboardEaProbe.mq5` копируется и компилируется в каждом терминале. Отличающийся существующий исходник автоматически не заменяется. Заверши первый запуск в каждом MT5:

1. Navigator → Services → Refresh, если сервис ещё не виден.
2. DashboardEaProbe → Add Service: создай **один** экземпляр и запусти его.
3. Оставь разрешения этого сервиса **Allow Algo Trading** и **Allow modification of Signals settings** выключенными.
4. Убедись, что `MQL5\Files\dashboard-eas.tsv` обновляется. Свежий пустой список означает отсутствие EA на графиках и является корректным результатом.

Сервис читает свойства графиков, не меняя торговые советники. Подробнее: [EA-мониторинг](eas.md). Установщик не кликает по торговому интерфейсу; незапущенный сервис явно попадёт в Check.

Обе задачи стартуют при **интерактивном входе пользователя MT5**. После перезагрузки без входа они не стартуют. Проверку перезагрузки и входа выполни отдельно в согласованное время; установщик сам сервер не перезагружает.

## 5. Одна команда диагностики

Подожди первый цикл счетов (несколько десятков секунд для нескольких MT5):

```powershell
.\scripts\setup_host.ps1 -Mode Check -Profile Full -Online
```

Для других профилей укажи Logs или Accounts. Без обёртки:

```powershell
python -m collector.diagnose --profile Full --online
```

Команда выводит JSON без секретов: хост, задачи, очередь, процессы, подтверждения отправки счетов, EA-отчёты и проблемы. `ready: true` и код выхода 0 означают успешные локальные проверки выбранного профиля; код 1 — незавершённые шаги. AutoTrading disabled отображается отдельно: установщик не включает торговлю сам.

Доставку подтверждает свежий ответ API на heartbeat, в том числе при тихих логах. Пустая очередь и /health сами по себе не доказывают доставку. Небольшой pending между пятиминутными отправками нормален; устаревшее подтверждение или ошибка отправки — проблема. Снимки счетов должны быть свежими, полными, соответствовать login/server и иметь подтверждение API. Старые worker-процессы без новых файлов состояния требуют контролируемого перезапуска обновлённой задачи; иначе Check честно сообщает отсутствие подтверждения.

Заверши настройку проверкой **этого host_id** в центральном дашборде: heartbeat, оба потока логов, все ожидаемые счета, позиции/PnL и EA. Сравни день PnL с MT5 History при выбранном UTC+3. Глобальный аудит может показывать проблему другого VPS; оцени новый хост отдельно.

## Если шаг не прошёл

| Симптом | Действие |
|---|---|
| Python не найден | Установи 64-битный Python 3.13; передай полный -PythonExe |
| 401 на первой отправке | Сверь host_id и токен на центральном сервере; исправь и повтори Install. Базу и очередь сохраняй |
| Ошибка TLS | Проверь дату, адрес и сертификат; не отключай проверку TLS |
| login: 0 / Invalid account | Проверь авторизацию в MT5 и введи достоверные login/server; не выдавай такой счёт за подключённый |
| EA-отчёт отсутствует/старый | Запусти один экземпляр сервиса в соответствующем MT5, проверь файл и счёт |
| Задача Ready | Прочитай последний run-logs/remote-collector-*.log; проверь Python, пользователя и доступ |
| MemoryError / повторные остановки | Сохрани время и traceback для диагностики причины; один перезапуск не считается исправлением |
| Уже есть задача/настройки | Check и проверка действующей установки: Install специально не перезаписывает её |

Ошибка до сохранения секретов допускает повтор Install с тем же планом: совпадающие файлы и база сохраняются. При частичном сбое после сохранения `.dashboard-remote.local.json` не удаляй базу и не запускай второй сборщик. Проверь настройки и восстанови только недостающий шаг:

```powershell
.\scripts\new_host_task.ps1 -Mode Install
# Только если монитор Full ещё не зарегистрирован и его настройки сохранены:
.\scripts\monitor_task.ps1 -Mode Install -Url https://46.225.132.195 `
    -SavedSettings .dashboard-monitor.local.json
Start-ScheduledTask -TaskName MT5CollectorRemote
Start-ScheduledTask -TaskName MT5DashboardMonitor
```

Если настройки монитора ещё не сохранены, создай их под тем же пользователем командой ниже (токен вводится скрыто), затем выполни Install с таким же SavedSettings:

```powershell
.\scripts\monitor_task.ps1 -Mode Save -SavedSettings .dashboard-monitor.local.json `
    -PythonExe 'C:\Users\Administrator\AppData\Local\Programs\Python\Python313\python.exe'
```

Не подставляй открытый токен в задачу. Для намеренной миграции старой задачи отдельно сохрани резервную копию настроек и экспорт задачи, затем обнови действие, сохранив базу и host_id. `new_host_task.ps1 -Mode Save -Accounts accounts.json` поддерживает счета; без -Accounts остаётся режим логов.

В отчёт включи host_id, профиль, число терминалов/полных снимков, часовой пояс, состояния задач, свежесть подтверждения доставки, pending и оставшиеся проблемы. Отдельно укажи, проверялась ли перезагрузка с входом пользователя.
